# Сайт ООО «ВСА» — инструкция по установке на сервер

Сайт: статические HTML-страницы + небольшой сервер на Node.js (Express), который
раздаёт страницы и обслуживает админ-панель (вакансии и партнёры).
База данных не нужна — данные хранятся в JSON-файлах в папке `data/`.

## 1. Требования

- Linux-сервер (VPS) **на территории РФ** — этого требует 152-ФЗ (ч. 5 ст. 18), и это указано
  в политике конфиденциальности сайта
- Node.js **18 или новее** (`node -v`)
- nginx
- Домен, A-запись которого указывает на IP сервера
- SSL-сертификат (например, бесплатный Let's Encrypt через certbot) — **обязателен**:
  в политике конфиденциальности сказано, что сайт работает по HTTPS

## 2. Состав папки

```
server.js              — сервер (Express)
package.json           — зависимости
.env                   — настройки: пароль админки, секрет, порт (НЕ публиковать)
data/vacancies.json    — вакансии (меняет админка)
data/partners.json     — партнёры (меняет админка)
*.html                 — страницы сайта; admin.html — админ-панель
css/, js/, fonts/      — стили, скрипты, шрифт Inter (всё локально, без внешних CDN)
images/                — изображения; images/partners-logo/ — логотипы партнёров
docs/                  — PDF сертификатов и допусков
```

Сервер отдаёт наружу только страницы `*.html` и папки `css/`, `js/`, `fonts/`, `images/`, `docs/`.
Всё остальное (`data/`, `.env`, `server.js`, `node_modules/` и т. д.) недоступно по ссылкам — 404.

## 3. Установка

```bash
# 1. Скопировать папку на сервер, например в /var/www/vsa-site
cd /var/www/vsa-site

# 2. Установить зависимости
npm ci --omit=dev

# 3. Проверить настройки в .env (см. раздел 4)

# 4. Пробный запуск — сайт откроется на http://IP-сервера:3000
node server.js
```

## 4. Настройки (.env)

```
ADMIN_PASSWORD=...     — пароль входа в админ-панель (уже сгенерирован, передайте заказчику)
PORT=3000              — порт, на котором слушает сервер
```

`ADMIN_PASSWORD` обязателен: без него сервер не запустится (встроенного пароля по умолчанию нет).
Вход в админку ограничен 5 неудачными попытками за 15 минут с одного IP; сессия действует 24 часа.

После изменения `.env` сервер нужно перезапустить: `pm2 restart vsa-site`.
Файл `.env` не должен попадать в публичные репозитории и архивы.

## 5. Постоянная работа (pm2)

```bash
npm install -g pm2
pm2 start server.js --name vsa-site
pm2 save
pm2 startup        # выполнить команду, которую выведет pm2, — автозапуск после перезагрузки
```

## 6. Домен и HTTPS (nginx)

`/etc/nginx/sites-available/vsa-site`:

```nginx
server {
    listen 80;
    server_name ooovsa.ru www.ooovsa.ru;

    client_max_body_size 3m;   # загрузка логотипов партнёров в админке (до 2 МБ)

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;   # нужен для защищённой cookie админки
    }
}
```

```bash
ln -s /etc/nginx/sites-available/vsa-site /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx

# SSL-сертификат и автоматический редирект http → https
certbot --nginx -d ooovsa.ru -d www.ooovsa.ru
```

Порт 3000 снаружи должен быть закрыт файрволом — доступ только через nginx.

## 7. Журналы сервера — не дольше 6 месяцев

В политике конфиденциальности указано, что журналы веб-сервера (IP-адреса посетителей)
хранятся **не более 6 месяцев**. Настройте ротацию логов nginx и pm2 соответственно,
например в `/etc/logrotate.d/nginx`: `rotate 26` при `weekly` (≈ 6 месяцев).
Для pm2: `pm2 install pm2-logrotate`.

## 8. Резервные копии

Заказчик меняет через админку следующие файлы — их нужно регулярно копировать:

- `data/` — вакансии и партнёры
- `partners.html` — сервер пересобирает карточки партнёров после каждого сохранения
- `images/partners-logo/partner-*` — логотипы, загруженные через админку

## 9. Обновление сайта

При выкладке новой версии **не перезаписывайте** перечисленные в разделе 8 файлы —
иначе пропадут правки заказчика. Остальные файлы можно заменять. После обновления:

```bash
npm ci --omit=dev
pm2 restart vsa-site
```

## 10. Использование

- Сайт: `https://ooovsa.ru/`
- Админ-панель: `https://ooovsa.ru/admin.html` — вход по паролю из `.env`
  - вкладка «Вакансии» — добавление, редактирование, скрытие, порядок
  - вкладка «Партнёры» — добавление с загрузкой логотипа, редактирование, скрытие, порядок
